摘要

把症状与八纲/六经/体质标签聚合成九维三态向量，做偏差能量、张力、显化势、中介流度、稳定系数计算，再识别吸引子并给出单维 ±1 的迁移路径与方剂排序。离线 H5 + Android WebView，无网络、无存储、无位置权限。

核心结构

  • 可解释推演：聚合 → 量化诊断 → 吸引子 → 迁移路径 → 方剂排序。
  • 安全边界：十八反/十九畏/相恶/妊娠/毒性检查；P2/P3/P4 修复留痕。
  • 不是医疗器械；不替代专业中医诊断。
