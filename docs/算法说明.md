# 三元九维辨证推演 v1.1 · 算法说明

> 本文档描述引擎层（engine.js）全部算法，公式与实现一一对应，供代码审计与复现。

## 〇、状态空间

- 维度：9 维（d1 本体 / d2 时间 / d3 空间 / d4 能量 / d5 信息 / d6 关系 / d7 秩序 / d8 价值 / d9 行动），各自承载三层（内核/动力/表达）或对应（内核/时空/动力/群序/知行）耦合关系。
- 三态：0 = 潜藏/不足、1 = 中和/适当、2 = 显化/亢盛。
- 状态空间：**3⁹ = 19683** 种状态向量；目标态 T = (1,1,1,1,1,1,1,1,1)（中和）。
- 耦合对（0-based 索引 [a,b]）：时位耦合(d2·d3)、能信耦合(d4·d5)、群序耦合(d6·d7)、知行耦合(d8·d9)。

## 一、步骤 1：症状/标签 → 九维状态向量 S（辨证即诊断）

`aggregateState(selectedSymptoms, selectedTags, ctx)`

1. **症状投票**：每个症状的 `v` 为维度→票值映射（如 四肢厥冷 `v:{3:-2, 8:-1, 0:-1}`），逐项累加并记录可解释轨迹。
2. **宏观标签锚定**：八纲标签权重 w=1，六经/体质标签权重 w=2；标签典型向量 `vec` 中非 1 的分量按 `(val−1)×w` 投票。
3. **三值化**：各维票值 `≥1.5 → 2`、`≤−1.5 → 0`、否则 `= 1`（票面强度 strength 单独保留用于展示）。
4. **症状级 tag 透传（v1.1 P2/P5）**：`ctx.symTags` 由界面层从所选症状的 `tag` 字段聚合（表虚/表实/瘀/寒/热/虚/痰湿/湿热/气郁/少阳等），供证候禁忌与指征互证读取，避免「选了症状但引擎无证据」。

## 二、步骤 2：诊断指标（§10）

`diagnose(S)` 输出：

- 偏差 Δ = S − T；偏差能量 `E = Σ|Δᵢ|`。
- 耦合差值 `coupleDiff`；张力指数 `tension = Σ|Sₐ−S_b|`（四耦合对差值之和）。
- 中介通畅度 `fluidity = ones/9`（处于中和 1 的维度占比）。
- 显化势能 `potential = (d1+d4+d8+d9)/4 × w7`，w7 随 d7 取值 0.6/1.0/1.2。
- 本体稳固系数 `stability = (d1+d7+d8)/3`（本体+秩序+价值协同，与 data.js 指标表、UI 一致）。
- 指标联动规则：张力高+通畅低 → 必须优先恢复中介通道；势能高+稳固低 → 虚火，禁强显化；稳固低+张力高 → 最危险组合；通畅高+张力低 → 健康可调节。
- 阻滞判定（§6.3 四类硬阻滞）：d6=2∧d7=0、d5=2∧d4=0、d9=2∧d8=0、d1=0∧d9=2。
- 耦合警示：耦合对差值 ≥2 记为明显恢复迹象/主要矛盾。

## 三、步骤 3：吸引子判别（§9.2）

`matchAttractor(S, dx, ctx)` 对 6 个吸引子（中和/枢转/潜藏/升举/显化/关系）计算适配度 `fit`：

- 结构特征打分（如潜藏：阴虚阳浮 +3、阳虚寒盛 +2、d1=d4=d8=0 同潜 +3 等；显化需过「显化门限」d4=2 ∨ (d3=0∧d2=2) ∨ (d5=2∧d4≥1)）。
- **宏观标签先验加成**：`ATTR_TAG_BOOST` 表（六经/体质/八纲 → 吸引子加成），读取 `ctx.tags ∪ ctx.liujing ∪ ctx.tizhi`（v1.1 中 `ctx.tags` 仅含八纲/六经名，体质只经 `ctx.tizhi` 传入，避免重复累加）。
- 按优先级顺序（中和→枢转→潜藏→升举→显化→关系）取最高分；分数 ≤0 时兜底回「中和」。

## 四、步骤 4–8：方剂检索、评分与禁忌（§11.2/§11.3)

`scoreFormulas(S, dx, attractor, ctx)`

### 4.1 匹配分

```
score = −Σ wᵢ·|Sᵢ − vᵢ|     （wᵢ：d1/d3/d7 承载维度 = 1.5，其余 = 1.0）
      + 吸引子契合（主吸引子 +4）
      + 标签互证（八纲/六经/体质标签与方剂适用辨证一致，≤+4）
      − 禁忌惩罚 P（硬拦截不入候选；软惩罚按等级扣分）
```

### 4.2 硬拦截（不入候选，单独列出）

- 妊娠禁用（妊娠状态特殊症状 + 孕期药表）。
- d1=0 禁强显化（本体未立禁发散攻坚）。
- 稳固系数 ≤0.5 禁强攻强汗。
- 证候禁忌：表虚自汗忌用（麻黄汤等）——v1.1 P2 起读取 `ctx.symTags` 中的「表虚」，症状 `自汗恶风` 即可触发。

### 4.3 软惩罚（保留候选但要降权）

- 证候指征不足：如补阳还五汤在无瘀血证据时降权——v1.1 P5 起读取 `ctx.symTags` 含「瘀」才视为证据充分。
- 慎用条件（孕期慎用药等）。

### 4.4 Top-3 增强字段（v1.1 P3）

`run()` 对通过方剂的 Top-3 附加：

- `compat`：原方配伍审查（十八反/十九畏/相恶/妊娠/毒性）。
- `compatFull`：**建议加味后的全方复查**——将各维度加减思路中含药条目并入原方后重新审查，避免「原方安全、加味中毒」漏报。
- `steps`：逐步迁移路径（见下）。
- `S1`：施加前 3 步后的预期下一状态。
- `advice`：按剩余偏差 × 药性向量映射表生成的加减思路。

## 五、逐步迁移路径（§11）

`buildPath(S)`：

- 每步**单维 ±1**，先升/收敛到**中介通道 1**，不可直接从 0 跳到 2 或反向。
- 层级递进顺序：先修复承载维度 **d1/d7/d3 → 关系 d6/d5 → 能量 d4 → 收敛行动 d9**（其余维度按偏差大小插入）。
- v1.1 P7：文案按起止态语义化（潜态要升发时提示「先升入中介通道 1，不可直跳显态 2」；显态要收敛时提示「先收敛回中介通道 1，不可直落潜态 0」），不再使用固定文案。

## 六、配伍禁忌审查

`checkCompat(herbList, ctx)`：

- 十八反表（含 v1.1 P4 补入的 **附子 → 半夏/瓜蒌/贝母/白蔹/白及**，附子按乌头类炮制品识别）。
- 十九畏表、相恶表、妊娠禁用/慎用表、毒性分级（大毒十去其六、有毒十去其七、小毒十去其八）。
- 输出条目带【反】【禁】【慎】【毒】等分级；UI 按危险等级着色。
