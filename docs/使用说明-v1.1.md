## 二、安装方法

1. 将 APK 传输到安卓手机（微信文件传输、数据线、网盘均可）；
2. 点击 APK 文件，允许"安装未知来源应用"；
3. 安装完成后桌面出现「三元九维辨证推演」图标（墨绿底九维雷达图标）；
4. 首次启动阅读免责声明后即可使用，**全程无需联网**。

## 三、功能导览

### 推演（主流程，三步向导）
1. **采症**：8 组共 75 项症状/体征（全身寒热、头身胸腹、饮食二便、睡眠情志、形体皮肤、舌象、脉象、病程情境），点选即可；
2. **辨证**：八纲（8）、六经（6）、体质（9）宏观标签录入，作为九维微观状态的锚定与校验；
3. **推演**：一键生成完整报告——
   - 九维状态向量 S + 雷达图（0潜/1和/2显三色）
   - 四大量化指标：张力指数、显化势能、中介通畅度、本体稳固系数（含阈值判级与指标联动规则）
   - 耦合对冲突警示、中介阻滞判定（§6.3 四类阻滞）
   - 六大吸引子判别（适配度打分明细公开，可解释）
   - 方剂 Top-3 推荐：匹配分、禁忌惩罚 P、君臣佐使解析、原文牵引路径 + 引擎逐步迁移路径（每步单维±1、必经中介、层级递进）、预期下一状态 S₁、药味加减思路、配伍禁忌审查日志（**原方审查 + 建议加味后全方复查两段式**）
   - 被硬拦截方剂列表及拦截原因（算法透明化）
   - 中和态（E=0）专卡：无需药物干预提示，不生成处方级推荐

### 方剂库
14 首经典方剂完整档案：九维向量、主吸引子、君臣佐使、牵引路径、适用辨证、禁忌条件、配伍解析。

### 知识库（11 个分栏）
九维定义 / 吸引子 / 演化规则 / 诊断指标 / 八纲映射 / 六经映射 / 体质辨识 / 药性映射 / 治则治法 / 配伍禁忌（十八反·十九畏·相恶·妊娠·七情）/ 药材库（66 味药：四气五味归经毒性 + 九维操作）。

### 记录
推演记录保存在本机 localStorage（最多 50 条），可逐条删除，无任何云端上传。

## 四、算法架构（对应 PPT 技术规划的落地实现）

```
症状/标签 → 加权投票聚合 → 九维状态 S
S → 偏差Δ=S−T / E / 张力 / 势能 / 通畅度 / 稳固系数
  → 吸引子适配度判别（含宏观标签先验加成 + 症状级 tag 证据）
  → 方剂评分 score = −Σwᵢ|Sᵢ−vᵢ| + 吸引子契合 + 标签互证 − 禁忌惩罚P
     · wᵢ：d1/d3/d7 承载维度加权 1.5
     · 硬拦截：妊娠禁用、d1=0 禁强显化、稳固系数≤0.5 禁强攻强汗、证候禁忌
       （表虚自汗忌用等证候禁忌已接入症状级 tag，症状自汗恶风即可触发）
     · 软惩罚：证候指征不足（结合症状 tag 判别瘀/寒/热/虚等）、慎用条件
  → 牵引路径生成（先 d1/d7/d3 → d6/d5 → d4 → d8/d2/d9，单维步进必经中介1，
    路径文案按起止态语义化生成）
  → 加减建议（剩余偏差 × 药性向量映射表）
  → 配伍审查（十八反/十九畏/相恶/妊娠/毒性，含建议加味后的全方复查；附子按
    乌头类识别与半夏/瓜蒌/贝母/白蔹/白及相反）
```

技术栈：原生 Android WebView 壳（Java） + 单页 H5 应用（原生 JS，零第三方依赖），
全部数据（方剂 14 首、症状 75 项、药材 66 味、禁忌规则、映射表 11 张）内嵌 assets，
本地 localStorage 持久化。较 PPT 规划的 Flutter+sqflite 方案，本实现零 SDK 依赖、
包体极小（源码 assets 约 96KB，构建后可实际核对），离线一致性与可审计性更强。
