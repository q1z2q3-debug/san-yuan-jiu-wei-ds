# 三元九维辨证推演 v1.1 · 架构说明

## 一、总体架构

本方案采用「原生 Android WebView 壳 + 单页 H5 应用」的离线实现：

```
┌────────────────────────────────────────────────┐
│  Android 壳（Java）                             │
│  MainActivity — WebView 加载 assets/index.html  │
│  （无网络权限、无存储权限、纯离线）               │
├────────────────────────────────────────────────┤
│  单页 H5（原生 JS，零第三方依赖）                │
│  index.html（布局/导航/免责声明）                │
│  css/app.css（墨绿九维雷达主题）                 │
│  js/data.js   数据层   —— 症状/方剂/药材/禁忌    │
│  js/engine.js 引擎层   —— 聚合/诊断/推荐/路径    │
│  js/app.js    界面层   —— 三步向导/渲染/记录     │
├────────────────────────────────────────────────┤
│  localStorage（推演记录，最多 50 条，无云端）     │
└────────────────────────────────────────────────┘
```

分层原则：**数据层只声明结构化数据，引擎层只做纯函数计算（可独立 Node 运行验证），界面层只负责交互与渲染**。引擎与数据层不依赖任何 DOM/BOM，这是本项目可测试性的基础。

## 三、构建链（build.sh）

| 步骤 | 工具 | 作用 |
| --- | --- | --- |
| 1/7 | aapt2 compile | 编译 res 资源为 zip |
| 2/7 | aapt2 link | 链接生成基础 APK 与 R.java（targetSdk 34） |
| 3/7 | javac --release 11 | 编译 MainActivity（-encoding UTF-8） |
| 4/7 | d8 --min-api 24 | 生成 classes.dex |
| 5/7 | aapt2 add / apkbuilder | 合并 assets 与 dex |
| 6/7 | zipalign -f 4 | 对齐（4 字节） |
| 7/7 | apksigner sign/verify | RSA 2048 签名并回读证书 |

SDK 依赖：`android/sdk`（build-tools 35.0.0 / platforms android-34），产物 `三元九维辨证推演_v1.1.apk`。
密钥库：`tcm9d.keystore`，别名 `tcm9d`，RSA 2048，有效期 10950 天（30 年）。

**验证记录**：构建链已在完整环境（build-tools 35.0.0 + android-34 + JDK 21 + zip）下执行通过，
产出签名 APK `三元九维辨证推演_v1.1.apk`（54,368 B）；`apksigner verify` 与 `aapt2 dump badging` 均通过，
包名 com.sanyuanjiuwei.bianzheng、versionName 1.1、minSdk 24 / targetSdk 34。

## 四、运行时数据流

```
用户点选（症状 chps + 宏观标签 chips）
        │
        ▼
UI.selectedSymptoms / UI.tags
        │  runInference()
        ▼
Engine.run(symptoms, tagObjs, ctx)
        ├─ aggregateState → 九维票值 votes → 状态向量 S（0/1/2）
        ├─ diagnose(S) → E/张力/势能/通畅度/稳固系数/阻滞/耦合警示
        ├─ matchAttractor(S,dx,ctx) → 吸引子 + 适配度明细
        ├─ scoreFormulas → 方剂评分/硬拦截/软惩罚 → passed/blocked
        └─ Top3 增强 → compat/compatFull/steps/S1/advice
        │
        ▼
renderResult → 报告卡片（雷达图/指标/吸引子/方剂卡/迁移总览/中和态专卡）
```

## 五、可维护性与测试支撑

- **引擎可独立运行**：`data.js + engine.js` 拼接后在 Node 中直接执行，全部推理逻辑可脚本化验证（见《引擎验证报告》）。
- **界面层可 jsdom 冒烟**：`data+engine+app` 内联进 index.html 后可在 jsdom 中模拟完整推演流程。
- **零依赖**：js 侧无任何第三方库，无网络请求，适合离线审计与重新打包。
- **版本控制**：v1.1 在 v1.0 基础上仅改 data.js/engine.js/app.js 三文件与版本号（AndroidManifest/index.html/build.sh），变更面小、可追溯（P1–P8 变更明细见《引擎验证报告》）。
